# Platform Intelligence V3 release notes

- Interactive acquisition chart dots with hover and click/tap pinning.
- Automatic direct-referral reward estimates from the referred user's first real verified payment.
- Free access, 100% coupons and unpaid referrals earn $0.
- Refunded or reversed source payments are not payable.
- Seven-generation network remains analytics-only; no downstream reward calculation.
- Superadmin can configure percentage or fixed first-payment reward rules.
- Top referral earners, per-referral ledger and automatic approved payables queue.
- Approval and settlement remain manual and audited.
- Existing V2 discretionary reward records remain available as legacy records.
- Requires production D1 migration `0045_referral_reward_intelligence.sql` after code deployment.
