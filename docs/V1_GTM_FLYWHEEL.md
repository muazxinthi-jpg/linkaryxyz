# Linkary V1 GTM Flywheel

This document is a locked V1 product and go-to-market requirement for the new Linkary build.

## Core thesis

Linkary V1 grows from two complementary acquisition engines:

1. Creator acquisition through a free Linktree-style public profile at `linkary.xyz/username`.
2. Founder acquisition through free/manual campaign tracking, reputation discovery, and low-cost paid contact unlocks.

These are not separate products. They must feed the same Linkary network and reputation graph.

## Creator-side acquisition engine

Creators should have a compelling reason to join Linkary even before they are invited into a paid campaign.

The default creator offering is free and includes:
- public `linkary.xyz/username` profile
- Linktree-style profile builder/editor
- avatar, bio, social links, custom links, featured content, campaign proof, Media Kit and Work With Me blocks
- verified X identity when X is connected
- Telegram and other platform identities when connected/verified later
- creator reputation and verified campaign history as it accumulates
- creator score when enough evidence exists
- profile analytics
- ability to receive campaign inquiries
- ability to invite other creators and projects
- referral attribution for directly referred paying commercial BillingAccounts

The public profile should be useful enough that creators want to share it as their professional Web3 identity page.

## Founder-side acquisition engine

Founders should be able to join Linkary at zero or very low cost and immediately receive value without forcing expensive external API usage.

Free founder experience:
- one project workspace
- discover creators, communities, promotional platforms and POCs/managers
- see public reputation summaries
- shortlist/save profiles
- limited contact unlocks
- limited active manual campaigns
- basic Linkary first-party tracking links
- basic campaign dashboard

Founder Starter, recommended launch price $9.99/month:
- one project workspace
- approximately 25 new contact unlocks per month
- previously unlocked contacts remain visible without consuming another credit
- unlimited manual campaigns subject to reasonable anti-abuse limits
- 12-month history
- campaign spend and outcome entry
- first-party Linkary click/registration/conversion tracking
- CSV export
- reputation/review access
- saved lists

Manual founder metrics must be labelled `manual` or `estimated`. They must never be presented as Linkary-tracked or provider-verified data.

## The two-sided flywheel

Creator joins for free
-> claims a useful public Linkary profile
-> shares it externally
-> invites creators and projects
-> becomes discoverable by founders
-> founder unlocks contact or sends inquiry
-> founder runs campaign
-> Linkary tracks first-party outcomes and/or founder enters manual campaign results
-> verified campaign history improves creator/platform/POC reputation
-> founder leaves Upvote/Downvote + optional 180-character short review
-> Linkary reputation graph becomes more useful
-> more founders use Linkary for campaign decisions
-> more creators want a Linkary profile because founders are searching there
-> network grows

## Public profiles are not optional decoration

The Linktree-style profile system is a core V1 GTM feature and must not be deprioritized as a cosmetic profile page.

For creators it is:
- acquisition surface
- professional identity
- campaign proof page
- media kit
- trust/reputation page
- inbound lead surface
- referral distribution surface

For projects/companies it is:
- public project identity
- verified social links
- campaign/reputation proof
- public discovery surface

The same profile engine may be reused for both profile types with type-specific blocks and data.

## V1 cost principle

Manual first.
First-party Linkary tracking second.
Paid external social APIs only when the customer tier and feature economics justify the cost.

Creator public profiles and manual founder campaign tracking should be capable of supporting large early user volume with very low marginal provider cost.

## Product priority implication

Before adding expensive automated intelligence, V1 should make the following loop excellent:

Invite/access
-> identity verification
-> creator/project profile claim
-> beautiful shareable Linkary profile
-> founder discovery
-> contact unlock/inquiry
-> manual campaign creation
-> Linkary tracked links
-> outcomes
-> reputation/reviews
-> invites/referrals

This loop is the initial Linkary network and GTM engine.
