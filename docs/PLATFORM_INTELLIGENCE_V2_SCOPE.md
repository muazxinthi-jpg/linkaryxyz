# Platform Intelligence V2 preservation scope

Platform Intelligence V2 is intentionally additive.

It changes only private Superadmin analytics presentation and read-side calculations derived from existing Linkary data.

It does not introduce a new migration or alter public product behavior.

Protected systems that must remain unchanged:

- canonical Linkary account identity
- Google/email/X provider identity recovery
- invite access and redemption
- seven-generation network construction
- public Invite and Network copy
- coupon and free-access entitlement behavior
- paid checkout and payment verification
- wallets and wallet export
- campaigns and tracking links
- personal and Project public profiles
- Project ownership and team access

Private referral reward writes remain governed by migration 0044 and its existing state machine. V2 adds no formula, automatic liability or user-facing economic promise.
