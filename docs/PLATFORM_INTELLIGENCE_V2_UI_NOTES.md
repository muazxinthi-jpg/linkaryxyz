# Platform Intelligence V2 UI notes

The V2 Superadmin dashboard keeps the existing Linkary operating-intelligence visual language and adds four dense but responsive modules.

## Overview

Executive Pulse sits above the existing daily charts so the first visible decision layer is conversion and stickiness, not raw event volume.

Growth Velocity uses three cards with current value, previous 30-day value and signed change. Positive, negative, flat and unavailable states are visually distinct without relying on color alone because the percentage text remains explicit.

Six-month history uses three separately scaled mini-series to avoid comparing unlike units on one axis.

## Referral Operations

Payables Command Center sits before the referral funnel and leaderboard. It is intentionally focused on approved outstanding items only. The full reward ledger remains below for audit history and review-state management.

## Growth Plan

Target Attainment consolidates five current-month actual-versus-target measures into one scan-friendly chart while preserving the detailed target cards and audited target editor.

## Responsive behavior

Desktop prioritizes side-by-side density. Tablet collapses history and velocity modules. Mobile collapses KPI and payables grids, keeps operational tables horizontally scrollable and keeps all settlement actions accessible.
